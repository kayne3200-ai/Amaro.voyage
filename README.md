# Carnet Mobile — Projet Spck Editor

Ce projet est écrit en **HTML5, CSS3 et JavaScript classique** sans étape de compilation.

## Ouvrir dans Spck Editor (Android / iOS)
1. Ouvrez **Spck Editor** et allez dans l'onglet **Projects**.
2. Appuyez sur **Clone Repo** et collez l'URL HTTPS de ce dépôt GitHub.
3. Ouvrez `index.html` et appuyez sur le bouton **Play** pour lancer l'aperçu en direct.
